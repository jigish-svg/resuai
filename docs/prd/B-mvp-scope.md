# B. MVP scope

- Sign-in (Google, email code). Resume import, editor, seven templates, export.

- Job input by paste or link with structured-data reading and clean fallbacks. Confirmation.

- Requirement extraction with quotes, kinds and necessity. Hybrid evidence matching with four states and reason codes. Score v1. Fit, evidence and requirement views with corrections.

- Evidence-backed tailoring with Accept, Reject, Edit and Accept all safe. Claim Validator everywhere.

- Cover letter, interview preparation, bounded voice practice, checklist.

- Documents with incremental evidence. Certification suggestions from a checked registry.

- Home, Applications list, Settings, landing page. Analytics events. Evaluation harness.

# A. PRD summary

- GetJobFit turns one resume and one job into an honest fit analysis, evidence-backed improvements, and an application pack.

- The engine is deterministic first, with validated model steps. The score is code, and it means fit.

- The interface has two destinations, an Application page with four tabs, and about twenty short screens.

- Payment is designed for (entitlements, usage, a provider boundary) and not built.

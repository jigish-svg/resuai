# 17. Application pack

| **Component** | **CURRENTLY BUILD** | **FROM FUTURE EXPERIMENT** | **FROM MONETIZATION HYPOTHESIS** |
|---|---|---|---|
| Fit analysis | BUILD NOW. Score, states, evidence, corrections. | Whether the whole fit stays free. | Whether it is gated (not planned: the fit is never gated). |
| Tailored resume | BUILD NOW. Change cards, derived version, export with guard. | Whether the first change is a free preview (Experiment 2). | Where the export or the rest of the changes are entitled. |
| Cover letter | BUILD NOW. Grounded, validated. | Whether users want it (Experiment 3). | Entitlement of generation or export. |
| Interview preparation | BUILD NOW. Text prep. Voice practice kept and bounded. | Whether an interview-first entry works (Experiment 5). | Entitlement of voice minutes or the pack. |
| Application checklist | BUILD NOW. Five items driven by real events. | Whether users act on it. | Full versus basic checklist. |
| Pack as a unit | BUILD NOW as a page with four tabs and a checklist. | Pack contents and order (Experiment 3). | Unit: per application, time-boxed pass, or subscription (Experiment 4). Pricing not decided. |

## Checklist items

| **Item** | **Completed when** |
|---|---|
| Resume reviewed | Set when the tailored resume is exported or the base resume is confirmed for this application. |
| Must-haves checked | Set when every To verify must-have is answered or acknowledged. |
| Cover letter reviewed | Set when the letter is validated and opened. |
| Job saved with link or notes | Set when a source link or note exists. |
| Follow-up date (optional) | A date the user chooses. |

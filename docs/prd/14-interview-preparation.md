# 14. Interview preparation

| **Part** | **Definition** | **Validation and note** |
|---|---|---|
| Likely job questions | Generated per requirement kind from templates, then phrased by a model. Behavioural for responsibilities and soft skills, role-specific for skills and tools. | Questions carry no candidate facts, so they need no evidence. |
| Evidence-backed talking points | For each question, a STAR-shaped outline built only from cited evidence items. | Each point lists evidence_ids. The Claim Validator runs. |
| Candidate-specific questions | Questions a reader of the resume would ask ("Tell me about {project}"). | Built from the resume; each cites its source item. |
| Questions requiring clarification | Where evidence is thin ("Your bullet does not say your role. What did you do?"). | The answer can become a user_statement evidence item after confirmation. |
| Gap guidance | For Unsupported or Needs attention requirements: an honest way to answer, plus a study suggestion from the checked registry. | Never suggests claiming experience the candidate lacks. A study suggestion is not evidence. |
| Questions to ask them | Up to five, from the job text only. | No outside company facts. |
| Voice practice | Kept, bounded: session length cap and a per-user cap. Written feedback afterwards: what went well, what to improve, next practice. | **FACT:** today it produces a readiness number that feeds a Final Score. **DECISION:** no number is shown and nothing reaches the score. |
| Score boundary | Practice and interview tables are not readable by the fit computation. A test asserts the score function has no such input. | DECISION |
| Gating | Never gated by a score. | DECISION |

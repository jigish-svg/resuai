# 29. Final product principles

**1.** Evidence over assumptions.

**2.** Fit score means fit, and nothing else.

**3.** A recommendation is not evidence. Completion needs proof.

**4.** Absence of evidence is not proof of absence. Say "not on your documents".

**5.** Verified means an outside record. An uploaded file is not verified.

**6.** A model never silently invents a candidate fact. Code validates every model output.

**7.** Deterministic logic first. A model only where rules cannot decide.

**8.** Every generated change shows original, proposed, reason, evidence and a decision.

**9.** Inferred requirements are never scored.

**10.** Practice, quizzes, clicks and purchases never move the score.

**11.** The interface stays simple even when the backend is complex. One screen, one decision.

**12.** Never add a feature merely because a competitor has it.

**13.** Unknown stays unknown. Unvalidated numbers are labelled as such.

**14.** Fair, visible billing. Payment comes after product correctness.

**15.** Untrusted content is data, never instructions.
